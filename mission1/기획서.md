# 나의 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들이 함께 봅니다.

## 무엇을 하려고

- 내가 본 영화에 대한 개인 취향을 S·A·B·C 등급으로 정리합니다.
- 친구들과 티어리스트를 함께 보며 영화 취향에 관해 이야기합니다.

## 화면과 동작

- 영화관처럼 어두운 분위기의 반응형 화면을 사용합니다.
- S·A·B·C 등급 칸과 아직 등급을 정하지 않은 영화를 위한 미분류 칸을 보여 줍니다.
- 각 영화 카드는 제목과 HTML 안에 포함된 포스터형 그래픽을 함께 보여 줍니다.
- 영화 카드를 원하는 등급 칸에 끌어 놓아 옮길 수 있습니다.
- 영화 카드를 먼저 선택한 뒤 S·A·B·C·미분류 버튼을 눌러서도 옮길 수 있습니다.
- 영화 제목을 입력해 새 카드를 추가할 수 있으며, 새 카드는 미분류 칸에 놓입니다.
- 빈 제목이나 공백만 있는 제목, 이미 존재하는 제목은 추가하지 않고 이유를 안내합니다.
- 영화를 선택한 뒤 삭제 버튼을 누르면 확인창을 거쳐 삭제합니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- 초기화 버튼을 누르면 확인창을 거쳐 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충
- 어쩔수가 없다
- 살인의 추억
- 올드보이
- 아가씨

## 완성 기준

- 최초 실행 시 추천 영화 5편이 포스터형 그래픽과 함께 미분류 칸에 표시됩니다.
- 영화를 끌어 놓거나, 영화를 선택한 뒤 등급 버튼을 누르면 해당 칸으로 옮겨집니다.
- 옮긴 영화는 항상 한 칸에만 표시됩니다.
- 빈 제목이나 공백만 입력하면 영화가 추가되지 않고 안내 문구가 나타납니다.
- 이미 있는 영화 제목을 대소문자나 앞뒤 공백만 바꾸어 입력해도 중복 추가되지 않고 안내 문구가 나타납니다.
- 새 영화를 추가하면 미분류 칸에 표시됩니다.
- 선택한 영화는 확인창에서 승인해야 삭제됩니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화 목록과 등급 배치가 유지됩니다.
- 초기화하면 사용자가 추가한 영화는 사라지고, 최초 영화 5편이 미분류 상태로 돌아옵니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 모든 기능을 사용할 수 있습니다.
- 외부 파일, 로그인, API 또는 서버 실행 없이 HTML 파일 하나로 열립니다.
