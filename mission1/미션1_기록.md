# 미션 1 기록 — 질문하며 기획하고 HTML 첫 버전 만들기

> 작성 기준: `기획서.md`의 완성 기준 11개와 화면·동작 항목을 두 초안(`영화_A_초안.html`, `영화_B_초안.html`)에 같은 행동으로 적용한 결과입니다.
> 확인 방법: Chrome(headless)에서 두 파일을 같은 순서로 실행해 자동 확인했습니다(`_compare_test.mjs`). 눈으로 본 느낌(디자인 등)은 두 파일을 열어 본 뒤 적었습니다.
> `※ 직접 기입` 표시는 AI 서비스명·모델명처럼 파일만으로는 알 수 없는 내용입니다. 제출 전에 채워 주세요.

## 1. 작업 개요

- 한 줄 소개: 친구들과 함께 보며 개인 영화 취향을 이야기하는 영화 티어리스트
- 첫 번째 AI(→ `영화_A_초안.html`): ※ 직접 기입 (서비스명 / 모델명)
- 두 번째 AI(→ `영화_B_초안.html`): ※ 직접 기입 (회사가 다른 AI의 서비스명 / 모델명)
- 최종 선택 파일: `영화_A_초안.html`
- 선택 이유(요약): 완성 기준 11개 중 통과·실패 항목이 두 파일에서 완전히 같았고, 차이는 화면 분위기뿐이었습니다. 기획서가 "영화관처럼 어두운 분위기"를 요구하므로 어두운 A를 이어서 쓰기로 했습니다.
- 수정본: `영화_A_수정본.html` (6장 참고)

## 2. AI가 먼저 질문하고 사용자가 결정한 내용

| 질문 주제 | 사용자의 결정 |
|---|---|
| 누가 쓰나 | 친구들과 함께 보며 이야기할 용도 |
| 목적 | 개인 취향 정리 |
| 등급 | S·A·B·C 네 단계와 미분류 칸 |
| 영화 이동 방식 | 드래그와 선택 후 등급 버튼을 모두 사용 |
| 초기 영화 | 기생충, 어쩔수가 없다, 살인의 추억, 올드보이, 아가씨 |
| 영화 관리 | 새 영화 추가와 기존 영화 삭제 지원 |
| 저장과 초기화 | 브라우저 자동 저장, 최초 상태 초기화(확인창 포함) |
| 새 영화 위치 | 미분류 칸 |
| 삭제 방식 | 영화를 선택하고 삭제 버튼을 누른 뒤 확인 |
| 중복 제목 | 추가하지 않고 안내 |
| 카드 구성 | 제목과 포스터형 그래픽 |
| 화면 디자인 | 영화관처럼 어두운 분위기, 반응형 화면 |
| 외부 의존 | 외부 파일·서버 없이 HTML 한 장으로 열림 |

## 3. 사용자가 결정한 부분과 AI가 구체화한 부분

### 사용자가 직접 결정한 부분

- 친구들과 함께 보며 개인 취향을 정리한다.
- 등급은 S·A·B·C로 구성한다.
- 드래그와 버튼 이동 방식을 모두 제공한다.
- 추천 영화 5편을 사용한다.
- 영화 추가·삭제, 자동 저장, 초기화를 제공한다.
- 제목과 포스터가 함께 있는 어두운 영화관 분위기의 반응형 화면을 사용한다.

### AI가 제안하고 사용자가 승인한 부분

- 미분류 칸을 둔다.
- 빈 제목과 중복 제목의 추가를 막고 이유를 안내한다.
- 삭제·초기화 전에 확인창을 표시한다.
- 완성 기준을 사용자가 직접 행동해 확인할 수 있는 문장으로 작성한다.

## 5. 두 초안 비교 (같은 행동 · 같은 기준)

### 5-1. 같은 행동을 한 결과

두 파일에 아래 행동을 같은 순서로 했습니다.

1. 처음 열기 → 2. `기생충`을 인생영화(S에 해당) 칸으로 드래그 → 3. `살인의 추억`을 눌러 강력추천(A에 해당)으로 이동 → 4. `헤어질 결심` 추가 → 5. 공백만 입력해 추가 → 6. ` 기생충 `(공백 포함) 다시 추가 → 7. 새로고침 → 8. 삭제 버튼 찾기 → 9. 초기화 → 10. 폭 390px 화면 확인

| 행동 | A 초안 | B 초안 |
|---|---|---|
| 1. 처음 열기 | 5편이 모두 미분류에 표시 | 동일 |
| 2. 드래그 이동 | 성공, 다른 칸에서는 사라짐 | 동일 |
| 3. 카드 선택 후 칸 선택 | 성공 (카드 클릭 → 팝업에서 칸 선택) | 동일 |
| 4. 새 영화 추가 | 미분류에 추가됨 | 동일 |
| 5. 공백만 입력 | 추가 안 됨, "영화 제목을 입력해 주세요." | 동일 |
| 6. 같은 제목 다시 입력 | **추가됨 (기생충 카드 2장)**, 안내 없음 | **동일하게 중복 추가됨** |
| 7. 새로고침 | 배치와 추가 영화 유지 | 동일 |
| 8. 삭제 | **삭제 버튼 없음** | **삭제 버튼 없음** |
| 9. 초기화 | 확인창 후 5편 모두 미분류로 복귀 | 동일 |
| 10. 390px 화면 | 가로 넘침 없음 | 가로 넘침 없음 |

|---|---|---|---|

| - | 등급 칸 이름 S·A·B·C | **실패 (인생영화·강력추천·좋음·아쉬움)** | **실패 (동일)** |

### 5-3. 기획서에 없는데 들어간 부분

| 구분 | A | B |
|---|---|---|
| 칸 이름 | 인생영화·강력추천·좋음·아쉬움 (기획서는 S·A·B·C) | 동일 |
| 화면 구성 | 상단 입력창 + 한 줄 부제 | 좌측 "영화 추가" 사이드바 + "사용 방법" 안내 + 저장 상태 표시 |
| 팝업 | 취소 버튼으로만 닫힘 | 바깥을 눌러도 닫힘 |
| 포스터 | 외부 이미지 URL, 실패하면 제목 카드 | 동일 |

### 5-4. 두 AI가 다르게 만든 부분 (같은 기획서)

- 색 분위기: A는 어두운 테마, B는 밝은 테마. 기획서의 "영화관처럼 어두운 분위기"를 A만 따랐습니다.
- 레이아웃: A는 한 열, B는 사이드바 + 보드. B는 안내 문구가 있어 처음 쓰는 사람에게 친절합니다.
- 같은 방식으로 틀린 부분: 중복 확인·삭제 기능·S·A·B·C 칸 이름·외부 이미지. 기획서에서 줄이 길거나("대소문자나 앞뒤 공백만 바꾸어도"), 한 줄에 여러 요구가 섞인 곳을 두 AI가 모두 놓쳤습니다.

### 5-5. 선택

- 선택: `영화_A_초안.html`
- 근거: 같은 행동 결과로는 두 파일의 차이가 없고, 기획서 항목 중 "어두운 분위기"에서만 갈렸습니다.
- 아쉬운 점: B의 사용 방법 안내와 바깥 클릭으로 팝업 닫기는 좋은 점이라, 이후 A에 더할 수 있습니다.
