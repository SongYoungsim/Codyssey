# 미션 4 기록

> 확인 방법: 모든 파일을 Chrome(headless)에서 같은 행동으로 실행해 확인했습니다. 숫자가 보이는 위치와 모양은 브라우저에서 한 번 열어 눈으로 확인해 주세요.
> 사용한 AI: ※ 직접 기입 (이 작업은 Claude Code, 모델 Sonnet 5.5에서 진행함) / 주요 대화 캡처 파일명: ※ 직접 기입
> 정직하게 적어 둘 점: 미션은 기능을 요청한 뒤 받은 파일을 확인하는 순서인데, 이번에는 한 대화에서 기획서 덧붙이기, 기능 추가, 확인까지 이어서 했습니다. 새 대화에서 다시 요청하는 5)단계는 원래 기능이 망가지지 않아 건너뜁니다.

## 더한 기능

- **칸마다 영화 개수 보여 주기** (S·A·B·C 등급 글자 아래, '아직 안 정한 영화' 옆)
- 선택 이유: 옮기기·추가·저장·처음으로 모두와 연결되는 기능이라, 하나를 더하면 원래 기능이 망가지는지 확인하기에 좋음. 기획서에 한 행동과 결과로 쓰기도 쉬움.
- 기획서 끝에 덧붙인 완성 기준 (`기획서.md`의 '추가 기능' 항목, 7줄):
  1. 처음 열면 S·A·B·C 0, 미분류 8
  2. '기생충'을 누르고 S → S 1, 미분류 7
  3. '센과 치히로의 행방불명'을 A칸으로 끌어 놓으면 A 1, 미분류 하나 줄어듦
  4. '헤어질 결심' 추가 → 미분류 하나 늘어남
  5. 다시 열어도 숫자가 그 칸의 카드 수와 같음
  6. '처음으로' → S·A·B·C 0, 미분류 8
  7. 기능을 더한 뒤에도 위의 기존 완성 기준이 모두 맞음

### 원래 기능이 망가지지 않았다는 확인

- 옮기기(누르기·끌기), 한 칸에만 있기, 추가, 빈 제목·중복 제목 안내, 새로고침 후 유지, '처음으로', 외부 파일 없음, 390px 화면 모두 원본과 같은 결과.

### 바뀐 곳 (원본과 비교, 4곳)

- 숫자 글자 모양 규칙 1줄(미분류 옆에서는 한 줄로 보이게)
- '아직 안 정한 영화' 버튼 안에 숫자 자리 추가
- 등급 칸 글자 아래에 숫자 넣기
- 그릴 때마다 미분류 숫자 다시 세기

저장 방식, 이동 코드, 추가·초기화 코드는 건드리지 않음.

## 안전 점검 요약

- 원본을 완성 기준대로 먼저 확인하고 그대로 두었다: 예
- 받은 파일에서 원래 기능도 다시 해 봤다: 예 (위 표)
- 새 기능이 보이기만 하는지 실제로 맞는지 해 봤다: 예 (보이는 숫자와 실제 카드 수를 칸마다 비교)
- 원래 기능이 망가졌을 때 멈췄는가: 해당 없음 (망가지지 않음)
- 대화 공유 전 개인정보 확인: ※ 직접 확인

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 이번에는 기능이 작아서 한 번에 통과했는데, 숫자를 따로 저장해 두는 방식이었다면 다시 열었을 때 숫자와 실제 카드 수가 어긋났을 수 있음. 완성 기준에 "다시 열어도 숫자가 카드 수와 같다"는 줄을 넣은 것이 그런 경우를 잡는지 이야기하고 싶음.
